# Swipe Heist

Swipe Heist is a fictional mobile arcade puzzle about guiding a stylized character through compact levels with one-thumb directional swipes.

## V0 loop

- Swipe up, down, left or right.
- Collect the objective token.
- Avoid moving hazards and blocked tiles.
- Reach the exit tile.
- Restart instantly after failure.

## Product direction

Future levels can add cameras, keys, alarms, disguises, crews, getaway vehicles, daily challenges, leaderboards, rewarded ads and cosmetic progression. These are fictional game mechanics only.

## Prototype metrics

- Tutorial understanding without explanation.
- Level completion rate.
- Restarts per session.
- Session length.
- D1 retention.

## Tech

Flutter for the first prototype. The V0 avoids external game-engine dependencies so the interaction loop stays cheap to test.
